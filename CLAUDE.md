# MODERN DRONE — FPV strike simulator (Unity 6, URP, PC, single-player)

## Layout
- All game content lives in `Assets/_Project/`. Code is split into asmdefs under `Scripts/` (namespace `ModernDrone.<Assembly>`):
  Core <- Damage, Drone, Video, Vehicles <- Missions, UI. Editor tools in `Editor/`, tests in `Tests/EditMode` and `Tests/PlayMode`.
- Tunable data goes in ScriptableObjects under `Data/` (warheads, armor materials, vehicles, drones).

## Conventions
- Physics layers are defined in `Scripts/Core/GameLayers.cs` and must match TagManager (checked by EditMode tests).
  `Module` layer is query-only (no physical collisions).
- Physics runs at 250 Hz (`SimConstants.PhysicsHz`). Menu `Modern Drone/Setup/Apply Project Settings` re-applies settings.
- The test scene `Scenes/ProvingGround.unity` is generated by `Modern Drone/Setup/Build Proving Ground Scene`; change the
  builder, not the scene by hand.
- Damage/ballistics math should be plain C# (no MonoBehaviour) so it can be unit-tested.

- Scenes: MainMenu (build index 0) -> Mission_01 / ProvingGround. `Modern Drone/Setup/Rebuild Everything` regenerates
  prefabs and all scenes from the builders in `Editor/`.
- Pilot control settings live in `ControlSettings` (JSON at `Application.persistentDataPath/controls.json`), edited by
  the in-game settings menu (`UI/SettingsMenu.cs`). Don't hardcode keys/axes in gameplay code — use `ControlInput`.
- Play mode only ticks while unfocused if `PlayerSettings.runInBackground` is on (needed for automated play checks).
